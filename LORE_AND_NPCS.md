# The Forest Fools - Lore et PNJ

Ce document sert de bible narrative pour rework l'histoire sans perdre ce qui existe deja dans le jeu.

Objectif :

- garder le jeu lumineux, aventure fantasy, pas horror pur ;
- garder le controle par commandes dans le terminal ;
- donner une vraie raison aux regions, aux pass, aux boss et au dragon ;
- lister les PNJ possibles a croiser pour preparer leurs images ;
- proposer les interactions, lieux et commandes a ajouter plus tard.

---

## Vision generale

Le monde de The Forest Fools doit donner l'impression d'un royaume vivant : villages, ports, champs, forets, marais, routes, chateaux, ruines et montagnes.

La menace ne doit pas etre juste "un dragon s'est reveille, va le tuer". Le dragon est lie a une ancienne promesse oubliee. Les gens ont transforme cette promesse en legende, puis en chanson, puis en blague. Quand les signes reviennent, personne ne comprend vraiment ce qui se passe.

Les "Forest Fools" sont des eclaireurs, vagabonds, chasseurs de rumeurs, mercenaires et aventuriers assez imprudents pour entrer dans les forets maudites quand les soldats refusent d'y aller. On les appelle des fools par moquerie, mais le royaume depend d'eux parce qu'ils vont la ou les cartes s'arretent.

Le joueur est l'un de ces Forest Fools.

## Mythe principal

### Le Premier Serment

Il y a longtemps, Elarion n'etait pas un seul royaume. Les plaines, les forets, les marais et les montagnes etaient controles par des peuples differents.

Pour mettre fin aux anciennes guerres, les seigneurs humains, les druides de Greenmarch, les clans lezards de Scalefen et les gardiens des montagnes d'Ashenreach ont signe le Premier Serment.

Ce serment promettait trois choses :

- les hommes ne bruleraient pas les vieilles forets ;
- les druides n'empecheraient pas les routes de traverser le royaume ;
- les clans du marais garderaient les eaux anciennes ;
- les montagnards surveilleraient la pierre noire sous Ashenreach.

Le serment fut scelle par un etre ancien : Vaelrith, le Dragon des Vieilles Racines. Il n'etait pas seulement un monstre. Il etait un gardien. Son feu ne servait pas a detruire, mais a marquer les promesses dans la pierre, le bois et le sang.

### La faute oubliee

Des siecles plus tard, les rois ont oublie pourquoi le serment existait.

Les routes ont coupe les forets.
Les mines ont creuse trop profond.
Les seigneurs ont transforme des lieux sacres en forts.
Les clans lezards ont ete repousses dans les marais.

Le dragon ne s'est pas "reveille". Il a senti que le serment etait brise. Son retour est le symptome d'un monde qui perd son equilibre.

La question finale n'est donc pas seulement :

"Peux-tu tuer le dragon ?"

Mais :

"Peux-tu comprendre ce que le royaume a casse avant que le dragon ne le brule pour le rappeler a tous ?"

## Structure de l'histoire

### Prologue - Mosswake Isle

Mosswake est une petite ile paisible qui sert de tutoriel. Les habitants vivent de peche, de petits champs, du phare et du port. Les premiers signes sont modestes : routes bloquees, slimes anormalement nombreux, eau verte dans les fosses, bateaux retenus au port.

Le maire Aldren impose un embargo : personne ne quitte l'ile tant que les routes ne sont pas sures.

Le joueur doit :

1. parler au maire ;
2. atteindre le niveau 2 dans Old Fern Forest ;
3. obtenir l'emplacement de Slime Hollow ;
4. vaincre le Slime King ;
5. recevoir le Harbor Pass ;
6. partir par Southwake Port.

Le Slime King n'est pas juste un monstre random. Il est le premier effet visible de la corruption du serment : la terre rejette une magie verte, molle et instable.

### Acte 1 - Crownvale

Crownvale est la region royale : plaines, villages, moulins, champs, capitale, routes officielles.

Le roi Rowen n'envoie pas le joueur "tuer le dragon". Il demande d'abord quelqu'un capable de comprendre pourquoi les routes tombent les unes apres les autres.

Le probleme local est Crownvale Keep. Le Hollow Baron, ancien seigneur lie au Premier Serment, garde encore la route de l'est. Il n'est plus vraiment vivant, mais il n'est pas juste "mort-vivant mechant". Il est le souvenir d'une promesse trahie par la noblesse.

Le joueur doit :

1. arriver a Crownport ;
2. rejoindre la capitale ;
3. parler au roi Rowen ;
4. obtenir l'emplacement de Crownvale Keep ;
5. vaincre le Hollow Baron ;
6. recevoir le Greenmarch Pass.

### Acte 2 - Greenmarch

Greenmarch est l'ancienne foret magique. Les arbres y sont vivants d'une maniere que les humains comprennent mal. La region doit etre belle, dense, verte, mysterieuse, pas forcement sombre.

Le probleme local est Thornwell Ruins. Le Thornwell Warden protegeait autrefois une racine-serment. Maintenant il etouffe les chemins, bloque les voyageurs et confond protection et emprisonnement.

Le joueur doit :

1. entrer dans Greenmarch ;
2. trouver Eldergrove ;
3. parler a Elder Maelis ou Sylra ;
4. obtenir l'emplacement de Thornwell Ruins ;
5. vaincre le Thornwell Warden ;
6. recevoir le Scalefen Pass.

### Acte 3 - Scalefen

Scalefen est le marais des hommes-lezards. Ce n'est pas une zone "sale" ou juste hostile. C'est un territoire ancien, vivant, spirituel, avec des regles differentes.

Scalefen est le nom officiel de cette region. Les cartes, le wiki, les commandes visibles et le lore doivent utiliser ce nom sans remplacer la region par un ancien nom de travail.

Le probleme local est Sunken Grotto. La Mirejaw Matriarch a pris le controle d'une pierre noyee liee au serment. Les eaux gardent les armes des disparus, et les scouts reviennent rarement.

Le joueur doit :

1. entrer dans Scalefen ;
2. parler a Matriarch Sytha ;
3. apprendre les coutumes locales ;
4. obtenir l'emplacement de Sunken Grotto ;
5. vaincre la Mirejaw Matriarch ;
6. recevoir le Ashenreach Pass.

### Acte 4 - Ashenreach

Ashenreach est la region finale : montagnes, pierres grises, grottes, anciennes mines, vents froids. Elle peut etre dangereuse sans etre full horror.

Le probleme local n'est plus un simple boss regional. Ashenreach contient les traces de la faute originale. Les mines ont touche la pierre noire sous la montagne. C'est la que le serment s'est vraiment fissure.

Le joueur doit :

1. atteindre Highpass ;
2. parler au scout ou au survivant ;
3. explorer les grottes et donjons ;
4. apprendre que le dragon n'est pas qu'un envahisseur ;
5. trouver Ashenreach Dragon Lair ;
6. affronter Vaelrith.

Plus tard, on pourra ajouter un choix final :

- combattre et tuer Vaelrith ;
- briser la corruption puis convaincre Vaelrith de repartir ;
- echouer et voir Elarion changer.

Pour l'instant, le jeu peut garder le combat final existant.

## Factions

### La Couronne de Crownvale

La couronne veut proteger le royaume, mais elle a aussi cache des fautes. Le roi Rowen n'est pas mauvais, il est fatigue et lucide. Il sait que ses cartes sont incompletes.

PNJ lies :

- King Rowen
- Princess Celiane
- Captain Valen
- Grand Advisor Merov
- Archivist Odran
- Knight Rowan

### Les Veilleurs de Greenmarch

Druides, rodeurs et esprits qui gardent la foret. Ils ne font pas confiance a la couronne, mais savent que le danger depasse leurs frontieres.

PNJ lies :

- Elder Maelis
- Sylra
- Eldrin
- Root Speaker
- Moss Oracle
- Feather Huntress

### Les Clans de Scalefen

Hommes-lezards, pecheurs de vase, chamanes et gardiens des roseaux. Ils jugent les gens par les actes, pas par les titres.

PNJ lies :

- Matriarch Sytha
- Sszar
- Kraxa
- Reed Guard
- Old Scaleless One
- Mist Priestess

### Les Survivants d'Ashenreach

Mineurs, soldats, ermites, pelerins et chasseurs de wyvernes. Ils vivent pres de la verite finale et preferent parler peu.

PNJ lies :

- Highpass Scout
- Thorek
- Kael
- Borun
- Grey Pilgrim
- Royal Archaeologist

### Les Forest Fools

Pas une guilde officielle au debut. Plutot un surnom donne aux gens qui entrent dans les lieux interdits.

Plus tard, le joueur peut decouvrir qu'il existait autrefois une vraie compagnie d'eclaireurs appelee "The First Fools", ceux qui signaient les cartes avant les rois.

## Boss et monstres avec lore

### Slime King

Premier boss. Il nait d'une source magique instable sous Mosswake.

Il doit rester un boss simple, presque mignon au debut, mais il annonce que quelque chose remonte du sol.

### Hollow Baron

Ancien noble de Crownvale. Il avait promis de garder une route ouverte entre la couronne et la foret. Quand la couronne a trahi le serment, il a choisi de garder la route fermee pour toujours.

Son combat doit ressembler a un duel contre une armure vide, pas juste un fantome random.

### Thornwell Warden

Gardien vegetatif de Greenmarch. Il etait cree pour proteger la racine-serment. Maintenant, il etouffe toute chose vivante qui approche.

Il n'est pas malefique. Il est bloque dans une mission devenue folle.

### Mirejaw Matriarch

Grande creature du marais. Elle garde la pierre noyee comme une mere garde un nid. Sa violence vient de la corruption de l'eau et de la peur des clans.

### Vaelrith, Dragon des Vieilles Racines

Boss final actuel. Gardien ancien du Premier Serment. Son retour est terrible, mais logique.

Il peut rester un combat final, mais le lore doit laisser la porte ouverte a une fin plus nuancee plus tard.

## Interactions possibles

### Interactions deja compatibles avec le jeu

- `talk` : parle au PNJ important ou au PNJ du sous-lieu.
- `cd town_hall` : entre dans la mairie.
- `cd tavern` : entre dans la taverne.
- `cd merchant` : entre chez le marchand.
- `cd blacksmith` : entre chez le forgeron.
- `cd dock` : va au quai.
- `sail` : voyage depuis un port autorise.
- `fight` : combat dans les zones dangereuses.
- `search` : fouille un lieu special.
- `buy` / `sell` : commerce.
- `sleep` : repos taverne.
- `train` : progression magique ou combat.

### Commandes a ajouter plus tard

Ces commandes ne sont pas indispensables tout de suite, mais elles iraient tres bien avec le rework histoire.

| Commande | But | Exemple |
| --- | --- | --- |
| `journal` ou `quests` | Voir les quetes actives | `journal` |
| `talk {npc}` | Choisir un PNJ precis quand il y en a plusieurs | `talk nora` |
| `rumors` | Demander des rumeurs en taverne | `rumors` |
| `ask {topic}` | Poser une question sur un sujet | `ask serment` |
| `codex` ou `lore` | Lire les pages de lore trouvees | `codex first oath` |
| `give {item} {npc}` | Donner un objet de quete | `give old net to tovin` |
| `board` | Lire le panneau d'affichage | `board` |
| `pray` | Interaction chapelle/sanctuaire | `pray` |
| `fish` | Mini action au port ou marais | `fish` |
| `gather` | Recolte plantes | `gather` |
| `mine` | Recolte minerais | `mine` |
| `bestiary` | Voir les monstres rencontres | `bestiary` |

Priorite conseillee :

1. `journal`

3. `rumors`
4. `codex`
5. `give`

## Progression narrative proposee

### Debut

Le joueur n'est pas choisi par une prophetie. Il est juste assez courageux ou fou pour aider.

Mayor Aldren :

- bloque le port ;
- demande de prouver que le joueur sait survivre ;
- revele Slime Hollow ;
- donne Harbor Pass.

Nora :

- dit que le phare a vu des "lumieres anciennes" au large ;
- ne dit pas tout au debut ;
- peut devenir le premier PNJ qui laisse entendre que le dragon etait un gardien.

### Milieu

Chaque region donne une partie de la verite :

- Crownvale : le royaume a cache les fautes politiques.
- Greenmarch : la foret se defend parce qu'elle a ete blessee.
- Scalefen : les humains ont mal compris les marais et les clans lezards.
- Ashenreach : les mines ont touche la pierre noire et reveille la dette.

### Fin

Le joueur arrive devant Vaelrith avec assez d'indices pour comprendre que :

- la couronne n'est pas innocente ;
- le dragon n'est pas seulement un envahisseur ;
- tuer le dragon peut sauver le royaume a court terme mais laisser le serment brise ;
- comprendre le serment peut ouvrir une meilleure fin plus tard.
